# Вишлист

Список желаемых подарков к дню рождения Антона (1 октября) с бронированием «Хочу подарить»:
гость выбирает подарок и пишет своё имя, владелец списка не видит, кто что дарит (сюрприз),
а помощник (хелпер) видит имена. Плюс праздничная обвязка: обратный отсчёт, календарь с фактами
дня и квизами, небо с днём/ночью и звёздами-пасхалками.

Сайт: https://eyeanton.github.io/wishlist/ (гости), `admin.html` — вход владельца/хелпера через Google.

## Стек
- Статичный сайт без сборки: `index.html`, `admin.html`, `app.js` (ES-модуль), `style.css`.
- Firebase (проект `wishlist-92432`): Realtime Database (данные), Auth (Google), Storage (фото подарков).
  SDK грузится с `gstatic.com` по версии `10.12.0`, `node_modules` не нужен.
- Хостинг — GitHub Pages с ветки `master`.
- Внешние сервисы на клиенте: курсы валют `open.er-api.com`; превью ссылок — через CORS-прокси
  (свой Cloudflare Worker `winter-dust-4aa9`, `allorigins.win`, `cors.lol`).

## Запуск локально
```sh
npm run serve      # = python3 -m http.server 8000
```
Открыть http://localhost:8000/ (гость) или http://localhost:8000/admin.html.
Модули не работают с `file://`, нужен любой http-сервер. Данные — боевые (та же база Firebase).

## Тесты
```sh
npm test           # = node --test, Node 20+
```
`tests/smoke.test.mjs`: синтаксис `app.js`, чистые утилиты (экранирование, ссылки, ключ брони,
склонения, цены), валидность конфигов Firebase и связность страниц. Сеть и Firebase не нужны.

## Правила базы
`database.rules.json` — источник правды для правил Realtime Database. Деплой вручную:
```sh
npx firebase-tools deploy --only database
```
Права: всё пишет только владелец (`OWNER_EMAIL`); гости пишут только флажок брони в `items/<id>`
и своё имя в `reservations/<id>/<ключ>`; `reservations` читает только хелпер (`HELPER_EMAIL`);
`sky/bonusStars` — общие звёзды-пасхалки, пишут все (с проверкой формы).
Правила Firebase Storage в репо пока не лежат (см. ARCHITECTURE.md).

## Структура

|---|---|

| `admin.html` | страница владельца/хелпера, `initApp({ isAdmin: true })` |
| `app.js` | вся логика (≈2800 строк, разделы `// ====== … ======`) |
| `style.css` | стили, светлая/тёмная тема |

| `tests/` | смоук-тесты |

Подробная карта модулей и потоков данных — [ARCHITECTURE.md](ARCHITECTURE.md).
